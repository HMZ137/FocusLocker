自律，不该依赖意志力。

我们最常见的失败，不是「不想努力」，而是「每一次分心都太容易」。 打开电脑想做正事，却被一个网页、一段视频、一场闲聊带走。 FocusLocker 想改变的是这一点——把「分心」变成一件需要绕过三道闸门的事， 而把「专注」变成默认选项。

01

环境设计，胜过临场意志

与其在「再玩五分钟」和「我该学习了」之间反复拉扯，不如把选择提前做好。锁屏时段一经设定，到点自动执行，不需要你此刻的坚持。

02

锁屏不是惩罚，是保护

锁住的是娱乐入口，而不是学习工具。白名单网站、AI 助手、待办与文件库都在锁屏内正常可用——该用的资源一样不少。

03

纪律要有「出口」，才算真诚

真遇到急事，验证码紧急退出、冷却时间、20 分钟硬上限——急事能办，偷懒没门。自律不该让人绝望，而该让人安心。

为专注而生的每一处设计

从「到点自动锁屏」到「锁屏中的学习体验」，FocusLocker 把自律做成了一套完整、可用的系统。

谁需要 FocusLocker

01

自习备考

每晚固定时段自动锁屏，白名单里只有学习需要的网站。查完资料想刷短视频？会被挡在遮罩之外。

02

家长管控

配置学习时段与最短锁定时长，孩子只能使用白名单网站。遇到难题可以用 AI 助手，而不是伸手要手机。

03

告别拖延

把「打开电脑先玩十分钟」变成不可能。验证码、冷却、20 分钟上限三道闸门，帮你守住每一个计划。

把「认真」写进底层

深度决定了「锁得住」。以下每一项，都是为「防绕过、不丢数据、不打扰」而做的设计。

单实例 + 独立持久分区

同一时刻只允许一个实例运行，并为浏览器视图使用独立持久分区，避免多实例并发写入导致登录态（cookie 数据库）冲突丢失。

会话安全

会话即时落盘

DeepSeek 等网站的登录会话 cookie 在变更后数秒内即刷写磁盘，异常退出也不会丢失已登录状态。

数据可靠

看门狗守护

主进程被强制结束后，看门狗在数秒内自动拉起；异常退出也会留下恢复路径，锁屏不会被「任务管理器」一关了之。

防绕过

硬性上限兜底

核心逻辑内置上限：紧急退出最长 20 分钟、延长锁屏最长 24 小时、计时器最长 24 小时——任何入口都绕不过这层约束。

纪律兜底

数据本地优先

配置、待办、专注统计全部保存在本机，不上传、不留痕；AI 能力通过你自己的 DeepSeek API Key 按需调用。

隐私友好

全局快捷键，锁定行云流水

所有高频操作都支持全局快捷键，覆盖在任意软件之上也能响应。

常见问题

关于锁屏、退出、数据与 AI，你可能想问的都在这里。

可以。白名单内的网站（如 DeepSeek、Kimi、网易云音乐、电子课本）在锁定期间照常可用，访问白名单以外的网站才会被拦下。白名单网站通过 config.js 配置，支持别名快速切换与显示缩放。

通过全局快捷键（Ctrl+Shift+Alt+F12）或界面按钮发起紧急退出：需要输入随机验证码并等待冷却倒计时，单次最长 20 分钟。锁屏未满「最短锁定时间」时无法发起，确保紧急退出只服务于真正的急事。

不容易。主进程被结束后，看门狗守护任务会在数秒内自动把它拉回来；计划任务方式启动的守护进程也独立于主进程存活。配合单实例保护，绕过的路径都被封死。

需要。FocusLocker 的 AI 助手通过 DeepSeek API 提供服务，你需要在 config.js 中填入自己的 API Key。配置好之后，答疑、待办管理、文件解析、控屏指令都可以直接用。

数据本地优先。配置、待办、专注统计全部保存在本机文件中；上传到文件库的资料也留在本机，仅在必要时作为上下文发送给你自己的 AI 服务。登录会话 cookie 会即时落盘，避免异常退出丢失登录态。

会。开启开机自启后，FocusLocker 会延迟数秒静默待命，一旦进入设定的锁定时段立即执行锁定，无需手动打开软件。
